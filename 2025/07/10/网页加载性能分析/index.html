网页加载性能分析
chenshanshu Lv4
  2025-07-10 14:12:24 2025-07-10 14:12

关键性能指标

  1. DNS 查询时间

通过 performance.timing.domainLookupEnd - performance.timing.domainLookupStart 获取。

  1. TCP 连接时间

通过 performance.timing.connectEnd - performance.timing.connectStart 获取。

  1. SSL/TLS 握手时间（仅 HTTPS）

通过 performance.timing.connectEnd - performance.timing.secureConnectionStart 获取。

  1. TTFB（Time To First Byte）

首字节到达时间，通过 performance.timing.responseStart - performance.timing.requestStart 获取。

  1. 资源下载时间

通过 performance.timing.responseEnd - performance.timing.responseStart 获取。

  1. DOM 解析时间

通过 performance.timing.domComplete - performance.timing.domLoading 获取。

  1. DOMContentLoaded 事件时间

表示 HTML 和同步 JS 加载完成的时间，通过监听 DOMContentLoaded 事件或 performance.timing.domContentLoadedEventEnd 获取。

  1. 页面完全加载时间（Load Event）

通过 performance.timing.loadEventEnd - performance.timing.navigationStart 获取。

用户体验指标

  1. 首次绘制（FP, First Paint）

通过 performance.getEntriesByType(‘paint’) 获取，需浏览器支持。

  1. 首次内容绘制（FCP, First Contentful Paint）

同上，通过 performance.getEntriesByType(‘paint’) 获取。

  1. 最大内容绘制（LCP, Largest Contentful Paint）

通过 PerformanceObserver 监听 largest-contentful-paint 类型。

  1. 首次输入延迟（FID, First Input Delay）

通过 PerformanceObserver 监听 first-input 类型（需实际用户交互）。

  1. 累积布局偏移（CLS, Cumulative Layout Shift）

通过 PerformanceObserver 监听 layout-shift 类型。

资源加载指标

  1. 资源加载时间

通过 performance.getEntriesByType(‘resource’) 获取所有资源的加载详情（如 JS、CSS、图片等）。

  1. 关键资源加载时间

筛选 performance.getEntriesByType(‘resource’) 中的关键资源（如主 CSS、JS）。

  1. 异步请求耗时

通过 performance.getEntriesByType(‘navigation’) 或 performance.getEntriesByType(‘resource’) 获取 XHR/Fetch 请求的耗时。

网页性能指标（基于 PerformanceNavigationTiming）

指标名称 描述 获取方式 标准时间（良好） 优化目标
DNS 查询时间 DNS 解析耗时 domainLookupEnd - domainLookupStart < 100ms 减少第三方 DNS 依赖
TCP 连接时间 TCP 握手耗时 connectEnd - connectStart < 200ms 启用 HTTP/2 或 HTTP/3
SSL/TLS 时间 SSL 握手耗时（仅 HTTPS） connectEnd - secureConnectionStart < 100ms 使用 TLS 1.3 或优化证书
TTFB（首字节时间） 从请求发起至收到第一个字节的时间 responseStart - requestStart < 500ms 优化服务端响应
资源下载时间 内容下载耗时 responseEnd - responseStart 取决于资源大小 压缩资源（如 Brotli）
DOM 解析时间 DOM 树构建完成时间 domComplete - domInteractive < 1s 减少阻塞渲染的 JS/CSS
DOMContentLoaded (DCL) HTML 和同步 JS 加载完成时间 domContentLoadedEventEnd - navigationStart < 1.5s 延迟非关键 JS
页面完全加载 (Load) 所有资源（如图片）加载完成时间 loadEventEnd - navigationStart < 2.5s 懒加载非首屏资源
首次绘制 (FP) 浏览器首次渲染像素的时间 performance.getEntriesByName(‘first-paint’)[0].startTime < 1s 优化关键渲染路径
首次内容绘制 (FCP) 首次渲染出文本/图片等内容的时间 performance.getEntriesByName(‘first-contentful-paint’)[0].startTime < 1.5s 内联关键 CSS
最大内容绘制 (LCP) 视口中最大内容元素的渲染时间 PerformanceObserver 监听 largest-contentful-paint < 2.5s 优化图片/字体加载
首次输入延迟 (FID) 用户首次交互到浏览器响应的延迟 PerformanceObserver 监听 first-input < 100ms 减少长任务
累积布局偏移 (CLS) 页面布局偏移的稳定性评分（0-1） PerformanceObserver 监听 layout-shift < 0.1 预分配尺寸/避免动态插入
