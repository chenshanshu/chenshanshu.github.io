css 实现一个高度不固定的弹窗，鼠标悬浮时展开，鼠标离开时收起

在不使用 js 的情况下，无法获取弹窗高度，而浏览器中需要是数值型发生变化才会有过度效果，比如width、top这些属性，所以我们需要使用其他方式来实现过渡效果。

这里我们可以使用max-height、interpolate-size、grid-template-rows这三种方式来实现过渡效果。

  1. 使用max-height属性，设置过渡效果，这个方法存在缺点，因为收起时，元素会先从max-height收起到实际高度，这期间没有过渡效果，容易造成卡顿的感觉。
  1. 使用interpolate-size属性，设置过渡效果，要注意这个属性的浏览器兼容性
  1. 使用grid-template-rows属性，这个属性兼容性尚可
