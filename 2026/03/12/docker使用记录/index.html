docker使用记录

新建一个容器

docker run -it –name shuidi-font -p 8090:8090 -v /home/chenss/shuidi-font:/shuidi-font shuidi-font:v20.19.3 /bin/sh -c “cd /shuidi-font && npm start”

进入一个docker容器

docker exec -it shuidi-font /bin/sh

停止服务

docker stop shuidi-font
docker rm shuidi-font

如何保存为镜像

docker ps
docker commit -a “你的名字” -m “修改了nginx默认首页” {容器id} shuidi-font:v1

将宿主的私钥挂载到容器

docker run -it
–name shuidi-font
-p 8090:8090
-v /home/chenss/shuidi-font:/shuidi-font
-v /root/.ssh:/root/.ssh shuidi-font:v1
/bin/sh
-c “cd /shuidi-font && npm start”

创建临时容器运行前端打包

docker run –rm -v $(pwd):/app -w /app shuidi-font:v2 sh -c “node –version && npm –version && npm install && npm run test8”
